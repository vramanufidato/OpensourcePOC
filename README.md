# OpensourcePOC

A collection of open-source proofs-of-concept, experiments, and reproducible setup guides.

## POCs

### 1. Magento 2.4.9 Test Store on Vagrant (Kali Linux)

A fully scripted local Magento test store — Mage-OS 3.5.0 (Magento 2.4.9 base) on a Kali Linux Vagrant VM with Apache, MariaDB 11.8 and Elasticsearch 8.19, loaded with 2,000+ sample products and a mock payment method (Check / Money Order). Includes the complete runbook, troubleshooting notes, screenshots and a ready-to-publish Medium article.

- 📁 POC: [`magento2-vagrant-test-store`](./magento2-vagrant-test-store)
- 📝 Blog draft: [`magento2-vagrant-test-store/blog/medium-blog-draft.md`](./magento2-vagrant-test-store/blog/medium-blog-draft.md)
